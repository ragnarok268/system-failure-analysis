# Reviewer Guide

## For Hiring Managers

Start with [PORTFOLIO_SUMMARY.md](../job_artifact/PORTFOLIO_SUMMARY.md) and [CASE_INDEX.md](../job_artifact/CASE_INDEX.md).

## For Technical Reviewers

Open one case folder, then read `CASE_CARD.md`, `PATCH_DELTA_SUMMARY.md`, and `VERIFICATION.md` before checking the copied files under `recovered_evidence/`.

## For Interviewers

Use the cases to discuss debugging approach, invariants, source-of-truth boundaries, and verification tradeoffs under incomplete evidence.
