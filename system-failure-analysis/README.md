# System Failure Analysis

Evidence-backed forensic debugging case studies across real open-source systems. The repo shows how failures were classified across UI/runtime/state/dependency/payment boundaries, how likely root causes were isolated, and how minimal patch patterns were documented with recovered evidence.

## Evidence Boundaries

Recovered patches, focused traces, and copied evidence artifacts are included in the repository. Where failing logs, passing logs, or runtime/test transcripts were not recovered, the gap is called out explicitly in the case materials rather than implied away.
